# Waslha — Public website

Static bilingual (AR/EN) marketing site for **وصلها (Waslha)**.

## Brand

| Item | Value |
|------|--------|
| Name | وصلها (Waslha) |
| Primary | `#FB3C04` |
| Font | Cairo |
| Market | Jordan |
| Contact | waslha.app@gmail.com |
| Logo | `public/img/logo.jpeg` |

## Run

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Contact

`contact.html` shows the support email **waslha.app@gmail.com**. Clicking it opens Gmail compose directly.

## Build

```bash
npm run build
```

Output goes to `dist/` for Firebase Hosting.
