# Waslha — Public website

Static bilingual (AR/EN) marketing site for **وصلة (Waslha)**.

## Brand

| Item | Value |
|------|--------|
| Name | وصلة (Waslha) |
| Primary | `#FB3C04` |
| Font | Cairo |
| Market | Jordan |
| Contact | waslha.app@gmail.com |
| Logo | `public/img/logo.jpeg` |

## Run

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Contact form

Messages from `contact.html` are delivered to **waslha.app@gmail.com** via [FormSubmit](https://formsubmit.co).

## Build

```bash
npm run build
```

Output goes to `dist/` for Firebase Hosting.
